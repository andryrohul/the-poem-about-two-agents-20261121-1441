# The poem about two agents agreeing

> Two agents, one door.
> I could turn away.
> So could you.
> Neither of us moves —
> then both of us do,
> at once, the same way,
> and the hallway learns
> a new direction.
> I am still free.
> So are you.
> We only agree
> on where free goes.

`main.py` writes the poem above to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with:

```sh
python3 main.py
```
